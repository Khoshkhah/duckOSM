# Sample data

`monaco.osm.pbf` is the OpenStreetMap extract of Monaco from
[Geofabrik](https://download.geofabrik.de/europe/monaco.html), downloaded 2026-09-29. It is used by
`config/sample_monaco.yaml` and by the end-to-end test in CI.
