# The rules of the Geofabrik layers (duckosm quack --geofabrik, geofabrik.rs): the tags of an OSM element give the
# feature class (fclass) and its code in each class of layers. One rule on each line:
#
#   <class> <code> <fclass> <condition> ...
#
# A condition is k=v, k=v1|v2 (one of the values), k=* (any value), k!=v1|v2 (no tag k, or another value) or !k (no tag
# k). All conditions of a rule must hold. The key of a rule is the key of its first condition. In a class, each key gives
# one row: the first rule of that key that holds, so a rule with more conditions comes before its general rule. A cafe
# with shop=bakery is a bakery row and a cafe row, as in Geofabrik's files. A node goes to the point layer of its class (pois), a way to the line layer
# (roads), and a closed way or a complete multipolygon to the area layer (pois_a, buildings_a).
#
# The source: Geofabrik's "OpenStreetMap Data in Layered GIS Format" (the free files, 2026-04-02, and the standard 0.8),
# corrected by the free files of Monaco (2026-11-17), which the documents do not always describe:
# - parking: only 5260 parking, also with access=private (no 5261 to 5264);
# - pois: no 2253 sport=swimming, 2267 miniature_golf, 2562 car_repair, 2593 vending_drinks, 2594 vending_tickets and
#   2704 to 2706 (a guidepost is tourist_info); the names are marketplace, artwork, fitness_centre, sports_hall, track;
# - the rows of one element come in the order of the keys: tourism, shop, historic, leisure, amenity, office, man_made;
# - transport: no public_transport=stop_position; 5641 is taxi;
# - traffic: 5204 is pedestrian_crossing; 5209 street_lamp and natural 4121 tree are in the free files;
# - landuse: 7217 scrub is natural=scrub.
