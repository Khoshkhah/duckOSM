# Use the network

Use the database of a built area: route on it, query it, ask it questions and draw it.

| Page | What you do there |
|---|---|
| [Route](../guides/route.md) | Find the way from A to B by car, on foot or by bike, with legal turns only. |
| [Walking](../guides/walking.md) | Use the network of the ways that people can walk on. |
| [Routing across modes](../concepts/multimodal.md) | Plan a trip that changes mode: walk, drive, walk. *Experimental.* |
| [Query the database](../guides/query.md) | Read the tables with SQL, from DuckDB, Python or another tool. |
| [Questions to ask the AI agent](../guides/ask-questions.md) | Ask the data questions in words. |
| [Draw a map](../guides/draw-map.md) | Draw the network as HTML pages, with no server. |
| [Drawing order](../guides/drawing-order.md) | Store which road a map paints over which: a bridge over the road under it. |
