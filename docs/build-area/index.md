# Build an area

Make the database of an area: get its OSM data, build the networks, fix the data, and add heights and boundaries.

| Page | What you do there |
|---|---|
| [Prepare an area](../guides/prepare-area.md) | Get the OSM file and the boundary of an area, and cut the file to the area. |
| [Build a network](../guides/build.md) | Build the routable networks of an area into one DuckDB file. |
| [Fix the OSM data](../guides/edit-osm-data.md) | Correct roads, buildings, nodes and turns on a map. Every output uses your fixes. |
| [Add elevation](../guides/elevation.md) | Add the ground height to each node and edge. |
| [Add administrative boundaries](../guides/admin-boundaries.md) | Add the country, county, municipality and district areas. |
| [Check a build](../guides/check-build.md) | Make the build check its own result and stop on a fault. |
