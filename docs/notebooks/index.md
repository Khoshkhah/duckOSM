# Notebook manual

The chapters of duckOSM's Python SDK are in one place: [**the notebook manual**](https://khoshkhah.github.io/duckOSM/book/).
Each chapter is one Jupyter notebook on Monaco, with the outputs of its last run. This page lists the chapters, with a
button to run each one in Colab and a link to download it. Each notebook installs duckOSM when it is not installed.

## Run a notebook on your computer

```bash
pip install "duckosm[all]" jupyterlab
jupyter lab
```

The notebooks write their files (`data/`, `out/`) in the folder of the notebook. Each one needs a connection to the
internet: it downloads the Monaco extract from Geofabrik.

The CI workflow runs the notebooks on each change of the code or of a notebook. A failed cell fails the workflow.
