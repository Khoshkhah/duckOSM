# Start

Install duckOSM and build your first network, on your computer or in the browser.

| Page | What you do there |
|---|---|
| [Install](../install.md) | Install the command line `duckosm` and the Python package, then do a quick start. |
| [Your first network](../first_network.md) | Build the network of Monaco, then query it, route on it and draw it. |
| [duckOSM Studio (browser)](../guides/studio.md) | Build, fix and export an area in a web page, with no install. |
